# 🐞 Bug Buster

Bug Buster is a terminal-based game that simulates real AWS misconfigurations and challenges players to fix them using their cloud knowledge — built using [Amazon Q CLI](https://aws.amazon.com/q/cli/).

---

## 🎮 Features

- 5 Levels of AWS configuration errors
- Topics: S3, IAM, Lambda, CloudFormation, Security Groups
- Interactive terminal UI with score, hints & final ranking
- Educational and fun — learn AWS best practices while playing!

---

## 🚀 How to Play

```bash
git clone https://github.com/your-username/bug-buster.git
cd bug-buster
